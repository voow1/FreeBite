# FreeBite · 不牛马厨房

手机优先的做饭决策产品：800 道菜谱、转盘选菜、多人菜单、食材匹配和购物清单。

- 网站：`site/bu-niu-ma-kitchen.html`，双击 `启动预览.cmd` 启动。
- 微信原生小程序：微信开发者工具导入仓库根目录；`project.config.json` 指向 `miniprogram/`。已生成代码和有效素材均随仓库提供，可以直接编译。
- 当前工程版本：**v1.16.3**，含四角色 240 帧透明图集、连续变速跑步和单次导航弹动。Git 推送与微信上传、审核、发布是独立流程；平台状态以[网站进度表](网站进度表.md)为准。
