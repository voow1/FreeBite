# 不牛马厨房｜微信小程序上传指南

当前交付版本：1.14.0。工程已生成并完成本地检查，尚未上传到微信。

## 1. 安装并登录微信开发者工具

从[微信官方开发者工具下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)安装 Windows 稳定版。打开后，用这个小程序的管理员微信扫码登录；使用其他微信时，需要先在小程序后台添加对应开发者。

## 2. 导入现成工程

选择“小程序”→“导入项目”，填写：

| 项目 | 填写内容 |
|---|---|
| 项目目录 | `C:\UGit\FreeBite`（整个仓库根目录） |
| AppID | `wxacaeeb9071a24ad2` |
| 项目名称 | 不牛马厨房 |
| 开发模式 | 小程序 |
| 后端服务 | 不使用云服务 |

根目录 `project.config.json` 会自动指向 `miniprogram/`。不要导入 `site`，不要选择公众号的 AppID，也不要额外创建空白模板覆盖工程。使用工具默认稳定基础库；异步组件需 2.11.2 以上，建议使用当前稳定 3.x 版本。

## 3. 编译并手机预览

点击“编译”，首次使用应出现慵懒小猫“云边小憩”的全屏选菜转盘。旧自由配色会迁移为已选角色的专属主题，饮食设置与记录继续保留；“我的 → 恢复默认”可切回小猫。首次下载各素材分包需要网络。该版本的菜图、字体与角色均随工程打包，核心功能无需配置业务域名或购买服务器，不需要关闭域名校验。

点击“预览”，用管理员或已添加的开发者微信扫描二维码。请至少检查：

1. 抽一次单人菜、一次多人菜单，连续重抽，确认箭头停在抽中菜名上。
2. 点击下一道菜，确认照片、食材和步骤同步；加入整桌购物清单。
3. 搜索菜库、切换分类，首次打开不同菜图能正常显示；断网加载失败后恢复网络可重试。
4. 输入“番茄、鸡蛋”，核对食材匹配；添加、勾选和移除购物条目。
5. 逐一切换四个角色，检查配色、四个导航图标和转盘中心图标同时切换，无椭圆底影或叠加道具；添加自定义菜；退出再进入检查记录保存。
6. 转发内置菜谱给另一个微信，检查详情页可打开；打开图片来源说明。

本地自动化检查不替代以上真机步骤。已有菜谱来自原站，部分自动补全做法仍需内容复核；本次已修正发现的蒜苗炒鸡蛋、丝瓜鸡蛋汤两个条目。

## 4. 上传开发版本

真机检查通过后，点击开发者工具右上角“上传”：

- 版本号：`1.14.0`
- 项目备注：`四角色专属轻盈主题与独立图标，保留转盘选菜、菜谱、食材匹配与清单。`

遇到管理员确认时，由你在微信中完成。上传成功后，公众平台“版本管理”里的“开发版本”会出现本次版本。**上传成功不等于上线。**

## 5. 审核与发布

返回公众平台“小程序”账号 →“版本管理”→“开发版本”→“提交审核”。按页面要求完成类目、隐私保护指引和测试路径等信息；备案及其他要求以账号实际提示为准。首页路径为 `pages/kitchen/index`，核心功能无需账号登录。

审核通过后，在“审核版本”中点击“发布”，才会成为用户可访问的线上版本。若退回，依据具体审核理由修改后重新上传。

## 工程位置与维护

- 原生代码：`miniprogram/`
- 工程配置：`project.config.json`
- 本地验收说明与布局截图：`上线资料/小程序验收/`
- 构建及测试脚本：`tools/miniprogram/`
- 本次更新前的项目文档：`旧项目文档/20261014-193943/`

导入、预览、上传均可直接使用已生成工程，不需要先运行构建脚本。后续从网站同步数据时，在仓库根目录依次执行：

```powershell
node tools/miniprogram/extract.cjs
python tools/miniprogram/assets.py
node tools/miniprogram/build.cjs
node --test tools/miniprogram/engine.test.cjs
node tools/miniprogram/verify.cjs
```

构建需要 Node.js、Python，以及 Pillow、fonttools、brotli；build.cjs 会自动重建小程序字体子集。`recipe-overrides.json` 保存已校订条目，不要删除。自动生成的 `.generated/` 为本地缓存及旧构建归档，不参与小程序上传。

分包规则依据：[微信分包加载](https://developers.weixin.qq.com/miniprogram/dev/framework/subpackages.html)、[分包异步化](https://developers.weixin.qq.com/miniprogram/dev/framework/subpackages/async.html)。
